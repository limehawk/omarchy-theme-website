# About Omarchy Themes

Omarchy Themes is a free gallery of community themes for [Omarchy](https://omarchy.org/), the Linux desktop from Basecamp. You can browse every theme by color, see its full terminal palette, read its README, and copy the one command that installs it.

## Who runs it

[Limehawk](https://limehawk.io), an IT company in Knoxville, Tennessee, builds and runs the site. It is an independent community project. The Omarchy project, 37signals, Hyprland, and Arch Linux do not run or endorse it. The source code is open under the MIT license at [github.com/limehawk/omarchy-theme-website](https://github.com/limehawk/omarchy-theme-website).

## Where the themes come from

Every theme lives in its author's own GitHub repository. We do not host or change theme files. Each day the site reads each repository's `colors.toml`, preview image, README, and star count from GitHub, and rebuilds every page from that data. The themes that ship with Omarchy are listed too, so you can compare them with community themes.

## How a theme gets listed

Authors [submit a theme](https://github.com/limehawk/omarchy-theme-website/issues/new?template=submit-theme.yml) by opening a GitHub issue. Before we list it, we check that the repository is a real Omarchy theme and we read what it installs. If a theme does more than set colors, such as installing an editor extension, its page says so before you install it. When a repository is deleted or goes private, the theme comes off the gallery.
